# apps/web-portal — Sovereign Portal C-137 (shipped static website)

This is the **zero-build, air-gap-safe** build of the Rick C-137 Twin Portal interface.
There is no bundler, no npm install and no runtime CDN dependency: every shader, style,
sound and widget is inlined or served from this directory.

Open `index.html` directly (`file://`), or serve the folder with any static server.

## Contents

| File | Purpose |
|---|---|
| `index.html` | The complete single-file portal: matrix-rain layer, WebGL vortex shader, WebAudio reactor, orchestrator HUD, SOE gateway bridge, PWA runtime. |
| `offline.html` | Offline fallback page served by the service worker. |
| `manifest.webmanifest` | PWA manifest (fullscreen, portrait, `#00ff88` theme, maskable icons, 2 shortcuts). |
| `sw.js` | Offline-first service worker with a dedicated CacheStorage handler that supports HTTP `Range` requests for 50 MB–1.5 GB quantized model weights. |
| `icons/` | `icon.svg`, `icon-192.png`, `icon-512.png`, `maskable-512.png` (generated by `tools/make_icons.py`). |
| `robots.txt` | Crawl policy; `/models/` is disallowed. |
| `nginx.conf` | Hardened nginx vhost: COOP/COEP, `wasm-unsafe-eval` CSP, gzip incl. `application/wasm`, `/models/` immutable + `Accept-Ranges`, no-cache `sw.js`, SPA fallback, optional `/health` `/orchestrate/` `/audit/` `/voice/` proxies to the SOE sidecar. |
| `Dockerfile` | `nginx:1.27-alpine-slim`, non-root, healthcheck. |
| `vercel.json` / `netlify.toml` / `_headers` | Equivalent headers for Vercel, Netlify and Cloudflare Pages. |

## Run locally

```bash
# straight from the filesystem
start index.html            # Windows
open index.html             # macOS
xdg-open index.html         # Linux

# or with a zero-dependency static server
python -m http.server 8080
# -> http://127.0.0.1:8080
```

> Service-worker caching and PWA installation only activate over `https://` or on
> `localhost` / `127.0.0.1`. From a bare `file://` URL the portal still runs fully —
> it just will not install or pre-cache.

## Deploy

```bash
# Cloudflare Pages
npx wrangler pages deploy . --project-name rick-portal-ui

# Docker
docker build -t sovereign-portal-c137 .
docker run -d -p 8080:80 --name rick_portal sovereign-portal-c137

# GitHub Pages — see .github/workflows/deploy-html.yml
```

## SOE gateway integration

`index.html` probes `/health`, then `http://127.0.0.1:8000/health`, and upgrades the
`SOE CORE` telemetry cell to `LINKED` when the Python Sovereign Orchestrator Engine is
reachable. The **SOE AUDIT** button then dispatches `POST /orchestrate/action` with
`action_id: "ORC-001"` and streams the resulting Merkle root into the HUD.

When no gateway is present the portal degrades cleanly to standalone offline mode —
all shaders, audio and HUD behaviour remain fully functional.

## Desktop `.exe`

The Windows executable bundles this directory and serves it from the frozen Python
gateway. See `apps/soe-core/desktop_launcher.py` and `windows/build-exe.ps1`.
